# FLAMES Relationship Calculator

## 📌 Project Overview
FLAMES Relationship Calculator is a fun web application that determines the relationship between two people using the popular FLAMES game logic. Users enter two names, and the application calculates the relationship result in an interactive and user-friendly way.

## 🚀 Features
- Simple and fun FLAMES relationship calculation
- Interactive web interface
- Instant result display
- Responsive design
- Beginner-friendly project

## 🧠 Technologies Used
- HTML  
- CSS  
- JavaScript  

## 📂 Project Structure
- `index.html` – Main webpage structure  
- `style.css` – Styling and layout  
- `script.js` – FLAMES calculation logic  

## ▶️ How to Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/Monicram/Flames-Project.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Flames-Project
   ```

3. Open the application:
   - Double-click `index.html`  
   **OR**
   - Open `index.html` in any web browser

## 🎯 FLAMES Meaning
- **F** – Friends  
- **L** – Love  
- **A** – Affection  
- **M** – Marriage  
- **E** – Enemies  
- **S** – Siblings
